## 📋 Sobre o Projeto

O **Weather Radar** é uma aplicação web responsiva que permite consultar informações meteorológicas em tempo real para qualquer cidade do mundo.

O projeto foi desenvolvido com fins acadêmicos para demonstrar o aprendizado no conceito e aplicação de APIs.

---

## ✨ Funcionalidades

### 🔍 Busca por Cidade

Permite consultar condições climáticas através do nome da cidade.

### 📍 Minha Localização

Obtém automaticamente a localização do usuário utilizando a Geolocation API.

### 🌡️ Informações Climáticas

Exibe:

* Temperatura atual
* Sensação térmica
* Umidade relativa do ar
* Velocidade do vento
* Cobertura de nuvens
* Pressão atmosférica
* Condição climática atual
* País e cidade consultados

### 🕒 Medidor de Atualização

Contador em tempo real indicando há quanto tempo os dados foram atualizados.

### 📝 Histórico Inteligente

Armazena as últimas 5 cidades pesquisadas utilizando LocalStorage.

### 🎨 Interface Dinâmica

Plano de fundo adaptável conforme a condição climática:

* Céu limpo
* Nublado
* Chuva
* Tempestade
* Neve
* Névoa
